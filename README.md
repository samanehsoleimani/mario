
این پروژه یک بازسازی از بازی محبوب ماریو است که با استفاده از زبان برنامه‌نویسی جاوا (Java)و با رعایت دقیق اصول شی‌گرایی (OOP)طراحی و پیاده‌سازی شده است.



هدف این پروژه پیاده‌سازی مکانیک‌های اصلی یک بازی پلتفرمر در محیط جاوا بوده است. تمرکز اصلی در این توسعه، بر روی **معماری تمیز (Clean Architecture)** و استفاده از اصول شی‌گرایی برای مدیریت موجودیت‌های بازی (Entity Management) بوده تا کد برای توسعه‌های آینده مقیاس‌پذیر باشد.

 - **Language:** Java (JDK 11+)
- **Architecture:** OOP (Object Oriented Programming)
- **Concepts:** Interfaces, Inheritance, Polymorphism, Encapsulation

## 💡 نکات فنی و معماری
این پروژه به صورت ماژولار نوشته شده است:
- **استفاده از اینترفیس‌ها (Interfaces):** برای تعریف رفتارهای مشترک بین موجودیت‌های بازی (مانند `Movable` یا `Collidable`) که باعث شده کد بسیار منعطف باشد.
- **وراثت (Inheritance):** برای کاهش تکرار کد (Code Duplication) در کلاس‌های شخصیت‌ها و دشمنان.
- **مدیریت رویدادها:** پیاده‌سازی منطق برخوردها (Collision Detection) برای تعامل دقیق اشیاء در محیط بازی.
